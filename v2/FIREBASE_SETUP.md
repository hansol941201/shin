# 한솔2(v2) 집/회사 동기화 설정 안내

한솔2의 코드는 이미 Firebase(Authentication + Firestore) 연동이 준비되어 있습니다.
다만 아래 **2가지는 Firebase Console에서 사람이 직접 눌러야 하는 설정**이라 코드만으로는
활성화할 수 없습니다. 이 2가지를 마치면 집 PC와 회사 PC에서 같은 데이터를 보게 됩니다.

이미 한솔(root, `index.html`)에서 쓰고 있는 Firebase 프로젝트(`pour-dashboard`)를
한솔2도 그대로 재사용합니다 — 새 프로젝트를 만들 필요가 없습니다.

**[중요 — 인증 방식 재검토 결과]** 처음에는 "익명 로그인(Anonymous)"으로 구현했었는데,
검토 결과 익명 로그인은 **기기/브라우저마다 서로 다른 사용자(uid)가 자동 생성**되는
방식이라 "집 PC와 회사 PC가 같은 사용자가 된다"는 목표에 애초에 맞지 않는다는 것을
확인해 **이메일/비밀번호(Email/Password) 로그인**으로 바꿨습니다. 새 로그인 화면을
따로 만들지는 않았고, 이미 있는 **사이트 잠금 비밀번호를 그대로 재사용**합니다 —
집/회사에서 같은 사이트 잠금 비밀번호를 입력하면 자동으로 같은 Firebase 계정(uid)에
연결됩니다.

---

## 1) 이메일/비밀번호 로그인 활성화

1. https://console.firebase.google.com 접속 → `pour-dashboard` 프로젝트 선택
2. 왼쪽 메뉴 **Authentication** → **Sign-in method** 탭
3. 제공업체 목록에서 **이메일/비밀번호(Email/Password)** 를 찾아 **사용 설정**으로 켜기
   (아래쪽의 "이메일 링크(비밀번호가 없는 로그인)"는 켤 필요 없습니다)

이 설정을 켜지 않으면 한솔2는 계속 지금처럼 **이 브라우저(이 PC)에만 저장되는 localStorage
전용 모드**로 정상 동작합니다 — 아무것도 깨지지 않습니다. 콘솔에는 아래와 같은 안내
로그만 남습니다(오류가 아니라 안내입니다):

```
[한솔2/Firebase] 이메일/비밀번호 로그인 실패 — Firebase Console에서 Authentication의
"이메일/비밀번호" 제공업체가 켜져 있는지 확인해주세요. localStorage 전용 모드로 계속 동작합니다.
```

**참고**: 실제로 존재하는 이메일 주소가 필요한 게 아닙니다(인증 메일을 보내지 않습니다).
앱 안에 고정된 식별용 이메일(`hansol2-owner@pour-dashboard.firebaseapp.com`)을 쓰고,
비밀번호는 사용자가 정한 사이트 잠금 비밀번호를 그대로 씁니다.

**주의**: Firebase 비밀번호는 최소 6자입니다. 사이트 잠금 비밀번호가 6자 미만이면
동기화 계정이 만들어지지 않고(콘솔에 안내 로그만 남고) 나머지는 그대로 정상 동작합니다 —
동기화를 쓰시려면 사이트 잠금 비밀번호를 6자 이상으로 설정해주세요.

## 2) Firestore 보안 규칙 게시

1. 같은 프로젝트에서 왼쪽 메뉴 **Firestore Database** → **규칙** 탭
2. 이 폴더의 `v2/firestore.rules` 파일 내용을 열어서 확인
3. 기존에 게시되어 있던 규칙(한솔 root용)이 있다면 **지우지 말고**, 그 안에
   `match /users/{uid}/shin2/{docId} { allow read, write: if request.auth != null && request.auth.uid == uid; }`
   블록만 추가해주세요 (파일 안에 "합쳐서 게시" 예시가 그대로 들어있습니다)
4. **게시** 버튼 클릭

이 규칙은 인증 방식(익명이든 이메일/비밀번호든)과 무관하게 "로그인한 본인의 uid
아래 문서만" 허용하는 구조라 — 1)번에서 인증 방식을 바꿔도 이 규칙은 수정할 필요가
없습니다.

---

## 확인 방법

두 설정을 마친 뒤 한솔2를 다시 열고, 사이트 잠금 비밀번호(6자 이상)를 입력해 잠금을
풀면, 브라우저 개발자 도구(F12) → Console 탭에서:

```
[한솔2/Firebase] 실시간 동기화 연결됨 (uid: xxxxxx…)
```

이 메시지가 보이면 정상 연결된 것입니다. **집 PC와 회사 PC 모두 같은 사이트 잠금
비밀번호**로 잠금을 풀어야 같은 계정(uid)으로 연결되어 동기화됩니다. 이후 한 PC에서
업체/업무/메모/지식/할일을 추가·수정하면, 다른 PC에서 한솔2를 열었을 때(또는 이미
열려 있다면 자동으로) 같은 내용이 보입니다.

**만약 두 PC의 사이트 잠금 비밀번호가 이미 서로 다르게 설정되어 있다면**, 어느 한쪽의
비밀번호로 통일해서 다시 입력해주셔야 동기화가 시작됩니다(비밀번호가 다르면 Firebase
쪽에서도 서로 다른 계정으로 인식됩니다).

## 지금 동기화되는 데이터 / 되지 않는 데이터

| 데이터 | 동기화 여부 |
|---|---|
| 업체관리 | ✅ |
| 오늘 확인할 업무 | ✅ |
| 메모(공통 메모 컴포넌트) | ✅ (단, 지금 열려 있는 화면은 다시 열어야 최신값이 보일 수 있습니다) |
| 지식 | ✅ |
| 내 할 일(TODO) | ✅ |
| 계정(외부 사이트 아이디/비밀번호) | ❌ 의도적으로 제외 |

계정함은 기기마다 다른 임의의 salt로 마스터 비밀번호를 유도해 비밀번호를 암호화하는
구조라, 지금 그대로 동기화하면 다른 기기에서 복호화가 실패해 계정함 자체를 열 수 없게
될 위험이 있어 이번에는 포함하지 않았습니다. 안전하게 동기화하려면 salt/암호화 방식
자체를 기기 간 공유 가능한 구조로 먼저 바꿔야 합니다.
