# 월말실적정리

한솔 POUR 공사실적 통합관리 화면을 파일 하나로 담아 둔 곳입니다.

## POUR공사실적관리.html

내려받아 **더블클릭**하면 브라우저에서 바로 열립니다.
로그인도, 인터넷 연결도 필요 없습니다. 메일이나 메신저로 이 파일만
보내면 받는 사람도 그대로 열어 봅니다.

### 들어 있는 것

- ＋ 새 공고 등록 (K-APT 공고번호 포함)
- 낙찰로 변경 · 낙찰 상세정보 입력
- 상세·수정 (① 공고 정보 / ② 낙찰 정보)
- 특허 내역 (POUR · DO · CNC · 타사공법 구분)
- 상태 탭 · 검색 · 상단 알림

### 자료

**예시 자료 7건**만 들어 있습니다. 실제 공사실적은 들어 있지 않습니다.
실제 자료는 운영 데이터베이스에만 두고 이 파일에는 담지 않습니다.

여기서 입력한 내용은 그 브라우저에만 남고 다른 사람에게 전달되지 않습니다.

### 다시 만들기

손으로 고치지 마세요. 원본을 고친 뒤 아래를 실행하면 다시 만들어집니다.

```
python3 pour-integration/scripts/build-preview.py
```
