# 테스트 이메일 발송 — 처음부터 끝까지 (초보자용)

목표: **"버튼 클릭 → PDF 첨부 이메일 1건, 내가 입력한 주소로 실제 수신"** 딱 여기까지만 확인합니다.
실제 고객 발송, 자동 발송은 아직 만들지 않았습니다.

절대 원본(`poursolution/pour-contract`) 저장소나 운영 사이트는 손대지 않습니다. 여기 있는
`index.html`은 완전히 별도 사본이고, 서버 함수도 **새로 만드는 테스트 전용 프로젝트**에만 올립니다.

---

## 1단계 — 테스트 전용 Google Cloud 프로젝트 새로 만들기 (기존 것과 완전히 분리)

1. https://console.cloud.google.com 접속
2. 상단 프로젝트 선택 메뉴 → **"새 프로젝트"** 클릭
3. 이름 아무거나 (예: `pour-email-test`) → 만들기
4. 만든 프로젝트를 선택된 상태로 유지 (기존 pour-contract 프로젝트 아님! 반드시 새 프로젝트인지 확인)

## 2단계 — 하이웍스 "메일 전용 비밀번호" 준비

이미 발급받으셨다고 하셨으니, 그 아이디/비밀번호만 손에 들고 있으면 됩니다.
(이 문서나 채팅 어디에도 비밀번호를 적지 마세요 — 3단계 화면에서 직접 입력합니다.)

## 3단계 — 서버 함수(Cloud Functions) 만들기 (마우스 클릭만)

1. 왼쪽 메뉴에서 **"Cloud Functions"** 검색 → 이동 (처음이면 API 사용 설정 버튼이 뜨면 클릭)
2. **"함수 만들기"** 클릭
3. 아래처럼 입력:
   - 환경: **2세대**
   - 함수 이름: `sendTestEmail`
   - 리전: `asia-northeast3` (서울) 또는 가까운 지역
   - 트리거: **HTTPS**
   - 인증: **"인증되지 않은 호출 허용"** 체크 (테스트 단계라 우선 열어둠)
4. "런타임, 빌드, 연결 및 보안 설정" 펼치기 → **"런타임 환경 변수"**에 추가:
   - `HIWORKS_USER` = 발송용 계정 아이디 (예: `netformb2b@netformrnd.com`)
   - `HIWORKS_PASS` = 방금 발급받은 메일 전용 비밀번호
5. "다음" 클릭 → 런타임: **Node.js 20** 선택, 진입점(Entry point): `sendTestEmail`
6. 인라인 편집기에서:
   - `index.js` 탭에 이 폴더의 `functions/index.js` 내용을 그대로 붙여넣기
   - `package.json` 탭에 이 폴더의 `functions/package.json` 내용을 그대로 붙여넣기
7. **"배포"** 클릭 → 몇 분 기다리면 초록색 체크 표시로 완료
8. 완료되면 함수 상세 화면에 **URL**이 보임 (예: `https://asia-northeast3-pour-email-test.cloudfunctions.net/sendTestEmail`) → 복사

## 4단계 — 사본 index.html에 서버 주소 넣기

1. 이 폴더의 `index.html`을 텍스트 편집기(메모장 등)로 열기
2. 맨 아래쪽에서 아래 줄을 찾기:
   ```
   const TEST_EMAIL_API_URL = 'https://REGION-PROJECT.cloudfunctions.net/sendTestEmail';
   ```
3. 따옴표 안을 8단계에서 복사한 진짜 URL로 교체
4. 저장

## 5단계 — 실제로 테스트하기

1. 저장한 `index.html`을 더블클릭해서 브라우저로 열기 (Firebase 데이터가 그대로 연결되어 있으니 기존 현장/시공사 목록이 그대로 보일 거예요 — 읽기만 하고 아무것도 안 바꿉니다)
2. 화면 오른쪽 아래에 보라색 **"🧪 테스트 이메일 발송 (PoC)"** 패널이 뜸
3. 현장 / 시공사 / 특허 아무거나 선택 (실제로 존재하는 아무 조합이나 상관없음 — PDF만 만들어서 테스트할 뿐, 발행 상태는 전혀 바뀌지 않음)
4. **수신 이메일 칸에 반드시 본인이 직접 확인 가능한 주소를 입력** (자동으로 채워져도 실수로 실제 고객에게 가지 않도록 꼭 확인)
5. 제목/본문은 아무거나 입력 (비워두면 기본값 사용)
6. **"📧 테스트 이메일 발송"** 클릭
7. 잠시 후 패널 하단에 "✅ 발송 성공!" 이 뜨면 성공 — 입력한 메일함(스팸함 포함) 확인
8. 실패하면 "❌ 발송 실패: ..." 메시지가 뜸 → 그 문구 그대로 알려주시면 원인 확인해 드릴게요

## 확인 포인트

- 이 테스트는 **PDF 생성만 실제 데이터로 하고, 발행 상태/DB는 전혀 저장하지 않습니다** (기존 "발행 확정" 버튼을 누른 게 아니므로 카드 상태는 그대로입니다)
- 테스트 끝나면 Cloud Functions 화면에서 이 함수를 삭제하거나, "인증되지 않은 호출 허용"을 꺼두면 더 안전합니다
