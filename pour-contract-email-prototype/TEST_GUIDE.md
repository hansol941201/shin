# 협약서 이메일 발송 — 재배포 & 문제 해결 가이드

## 지금 상황

사이트에서는 "발송 성공"으로 뜨는데 실제 수신함(`netformrnd@netformrnd.com`)에는 메일이
안 보이는 문제를 조사했습니다. `functions/index.js`를 고쳐서 **SMTP 서버가 실제로 뭐라고
응답했는지(수락/거부 목록, 원문 응답)**를 로그와 응답에 남기도록 했습니다 — "성공" 문구만
보고 넘어가지 않고, 실제 근거로 확인할 수 있게 하기 위해서입니다.

**이 코드는 아직 재배포 전이라 지금 서버에는 반영 안 된 상태입니다.** 아래 순서로 재배포 →
재테스트 → 로그 확인까지 해주셔야 원인을 정확히 짚을 수 있습니다.

---

## 1단계 — 함수 재배포 (기존 함수 URL 그대로 유지됨)

1. https://console.cloud.google.com → Cloud Functions → `sendTestEmail` 함수 클릭
2. **"수정"** 클릭 → 인라인 편집기로 이동
3. `index.js` 탭 내용을 이 폴더의 `functions/index.js`로 **전체 교체**
   (`package.json`은 안 바뀌었으니 그대로 둬도 됨)
4. 환경변수(HIWORKS_USER/HIWORKS_PASS)는 이미 설정되어 있으니 다시 입력할 필요 없음
5. **"배포"** 클릭 → 완료까지 대기 (URL은 바뀌지 않음)

## 2단계 — 사이트에서 실제 테스트 발송

1. `index.html`(또는 이전에 받으신 사본) 열기
2. 발행 미리보기에서 **"📧 메일 보내기"** 클릭 (수신 이메일이 `netformrnd@netformrnd.com`으로
   등록된 업체를 선택하거나, 업체관리에서 그 주소로 먼저 등록)
3. "✅ 발송 접수 완료" 또는 "❌ 발송 실패" 팝업 확인
4. **"📨 발송 이력 보기"** 클릭 → 방금 보낸 건의 상세 내용에 `SMTP: ...` 로 시작하는
   줄이 있는지 확인 (SMTP 서버의 원문 응답)

## 3단계 — 그래도 안 보이면, Cloud Run 로그 확인 (가장 확실한 방법)

1. Google Cloud Console → **Cloud Run** (또는 Cloud Functions 2세대는 Cloud Run에 같이 뜸)
   → `send-test-email` 서비스 클릭
2. 상단 **"로그"** 탭 클릭
3. 방금 보낸 시간대의 로그에서 `[sendTestEmail] SMTP 응답` 으로 시작하는 줄을 찾기
4. 그 줄의 `accepted`, `rejected`, `response` 값을 그대로 복사해서 알려주세요
   - `rejected`에 수신 주소가 들어있으면 → 하이웍스가 그 주소를 거부한 것 (주소 오타,
     수신 차단 등)
   - `response`에 `250`으로 시작하는 메시지가 있으면 → SMTP 접수까지는 정상, 그 이후
     (하이웍스 내부 스팸 처리 등)에서 막혔을 가능성이 큼 → 4단계로

## 4단계 — 수신 측 확인 (SMTP 접수까지는 정상인 경우)

- `netformrnd@netformrnd.com` 계정으로 로그인해서 **스팸함/정크메일함** 확인
  (가장 흔한 원인입니다 — 다른 SMTP 클라이언트에서 온 메일을 하이웍스가 자체적으로
  스팸 처리하는 경우가 있음)
- 그 계정에 메일 필터/규칙이 걸려 있어서 다른 폴더로 자동 분류되지 않았는지 확인
- 그래도 없으면, 하이웍스 관리자 페이지에서 "발신 제한" 또는 "외부 SMTP 발신 차단" 같은
  보안 설정이 있는지 확인 (일부 그룹웨어는 자사 도메인이라도 SMTP 릴레이로 들어온 메일을
  막는 정책이 있음)

## 참고 — 저는 왜 직접 테스트 메일을 못 보내는지

이 작업 환경은 보안 정책상 등록된 소수의 사이트(GitHub, npm 등) 외에는 외부 네트워크 접속이
막혀 있습니다. Cloud Run 서버 주소로 직접 요청을 보내려고 시도했지만 프록시에서
`403(정책 차단)`으로 거부되는 것을 확인했습니다. 그래서 실제 발송은 사용자분의 브라우저에서
진행해주셔야 하고, 그 결과(이력 화면 또는 Cloud Run 로그)를 알려주시면 그걸 근거로 다음
원인을 좁혀 드리겠습니다.
