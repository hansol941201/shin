====================================================================
AI 전략회의실 — 설치 및 사용 안내 (Windows)
====================================================================

이 프로그램은 집 PC와 회사 PC 어디서든, 폴더를 통째로 복사해서
사용할 수 있습니다. Python이나 Node.js 설치가 필요 없습니다.


--------------------------------------------------------------------
[처음 한 번만 하면 되는 준비 작업]
--------------------------------------------------------------------

1) Claude Code 설치 (PC마다 최초 1회)

   Windows PowerShell을 열고 아래 명령을 입력합니다.
   (시작 메뉴 → "PowerShell" 검색 → 실행)

       irm https://claude.ai/install.ps1 | iex

   * 이 설치 방식은 Node.js를 별도로 요구하지 않는 Claude Code의
     공식 네이티브 설치 방법입니다.
   * 만약 이 명령이 동작하지 않는다면(사내 정책 등으로 막힌 경우),
     https://docs.claude.com/ko/docs/claude-code 공식 문서에서
     현재 사용 가능한 Windows 설치 방법을 확인해주세요.
   * 이 부분은 사내 보안 정책에 따라 회사 PC에서는 IT 담당자의
     설치 허가가 필요할 수 있습니다.

2) Claude 계정 로그인 (PC마다 최초 1회)

   따로 PowerShell이나 명령 프롬프트를 열어서 명령을 입력하실
   필요가 없습니다. (설치를 마쳤다면 바탕화면 "AI 전략회의실" 아이콘을,
   설치 전이라면 "AI전략회의실.bat"을) 더블클릭하면:

     - 프로그램이 로그인 여부를 자동으로 확인합니다.
     - 아직 로그인되어 있지 않다면, 프로그램이 로그인 절차를
       자동으로 실행하고 Chrome 등 기본 브라우저 창이 저절로
       열립니다.
     - 그 브라우저 창에서 평소 쓰시는 Claude 계정으로 로그인/
       승인만 해주시면 됩니다.
     - 승인이 끝나면 프로그램이 로그인 완료를 자동으로 다시
       확인하고, 이어서 AI 전략회의실을 자동으로 실행합니다.

   ⚠ 중요: 로그인할 때 "Claude 구독 계정(Pro/Max/Team 등)"으로
   로그인해야 별도의 API 사용료 없이 사용할 수 있습니다.
   "Anthropic Console(API 키)" 계정으로 로그인하면 사용량만큼
   별도로 과금되니 주의해주세요. (기본값은 구독 계정 로그인입니다.)

   한 번 로그인해두면, 같은 PC에서는 다음에 실행할 때부터 로그인
   과정 없이 바로 AI 전략회의실이 시작됩니다.


--------------------------------------------------------------------
[설치 방법 — 처음 압축을 풀었을 때 한 번만]
--------------------------------------------------------------------

이전에는 압축을 푼 폴더를 통째로 들고 다녀야 했고, "AI전략회의실.bat"
파일만 따로 바탕화면에 옮기면 scripts\run.ps1을 찾지 못해 오류가
났습니다. 이제는 설치 과정을 한 번 거치면 바탕화면에 아이콘 하나만
남고, css/js/scripts 같은 내부 파일은 신경 쓸 필요가 없습니다.

1) 압축(zip)을 아무 폴더에나 풉니다(바탕화면이어도 상관없습니다).

2) 풀린 폴더 안의 "설치_AI전략회의실.bat"을 더블클릭합니다.
   - 프로그램 파일 전체가 다음 위치로 자동 복사됩니다:
       %LOCALAPPDATA%\AI전략회의실
       (보통 C:\Users\사용자이름\AppData\Local\AI전략회의실)
   - 바탕화면에 "AI 전략회의실" 바로가기 아이콘이 하나 생깁니다.
   - "설치가 완료되었습니다!" 문구가 나오면 성공입니다.

3) 설치가 끝나면, 방금 압축을 풀었던 폴더는 삭제해도 됩니다
   (프로그램은 설치된 위치에서 독립적으로 동작합니다).

4) 이후로는 바탕화면의 "AI 전략회의실" 아이콘만 더블클릭하면 됩니다.
   더 이상 css/js/scripts 폴더나 .bat 파일을 직접 찾을 필요가
   없습니다.

※ 예전처럼 설치 없이 바로 실행하고 싶다면, 압축을 푼 폴더 안의
   "AI전략회의실.bat"을 그대로 더블클릭해도 동작합니다(이 경우 폴더
   전체를 항상 그대로 유지해야 합니다). 다만 대부분의 경우 위 설치
   방법을 권장합니다.


--------------------------------------------------------------------
[제거 방법]
--------------------------------------------------------------------

1) 압축을 풀었던 폴더 안의 "제거_AI전략회의실.bat"을 실행하거나,
   설치 위치(%LOCALAPPDATA%\AI전략회의실) 안의 같은 파일을 실행합니다.
   (설치_AI전략회의실.bat이 이 파일도 함께 설치 폴더로 복사해두므로,
   압축 폴더를 이미 지웠어도 설치 폴더 안에서 실행할 수 있습니다.)

2) "정말 제거하시겠습니까?" 물음에 y를 입력하면:
     - 프로그램 폴더(%LOCALAPPDATA%\AI전략회의실)
     - 바탕화면 "AI 전략회의실" 바로가기
   가 삭제됩니다.

※ 회의 중간저장/과거 회의 기억은 이 프로그램 폴더가 아니라 브라우저
   저장공간(localStorage)에 있으므로 제거해도 지워지지 않습니다.


--------------------------------------------------------------------
[매번 사용하는 방법]
--------------------------------------------------------------------

1) 바탕화면의 "AI 전략회의실" 아이콘(설치를 마쳤다면)을 더블클릭합니다.
   (설치를 하지 않았다면, 폴더 안의 "AI전략회의실.bat"을 더블클릭합니다.
   이 경우 index.html만 따로 옮기면 동작하지 않습니다 — css, js,
   scripts 폴더가 모두 같은 위치에 있어야 합니다.)

2) 검은 창이 뜨고 자동으로 상태를 확인한 뒤, 문제가 없으면
   기본 웹 브라우저가 자동으로 열립니다.

3) 브라우저 화면에서:
     - 주제 입력
     - (필요하면) 참고자료 파일 선택
     - "전략회의 시작" 클릭
   → 이 PC에 로그인된 Claude Code가 실제로 7명의 전문가 역할로
     서로 반박·검증하며 회의를 진행하고, 완성된 보고서를 보여줍니다.

4) 다 사용했으면 검은 창을 닫으면 프로그램이 종료됩니다.


--------------------------------------------------------------------
[화면에 오류 안내가 나오는 경우]
--------------------------------------------------------------------

"Claude Code가 설치되어 있지 않습니다"
  → 위 [1) Claude Code 설치] 순서를 진행해주세요.

"Claude 로그인이 필요합니다"
  → 잠시 후 브라우저 창이 자동으로 열립니다. 그 창에서 로그인/
    승인만 해주시면 자동으로 이어집니다. (직접 명령을 입력하실
    필요는 없습니다)

"로그인을 확인하지 못했습니다"
  → 브라우저에서 로그인 승인을 마치지 않았거나 창을 닫으신
    경우입니다. AI전략회의실.bat 을 다시 더블클릭해 로그인을
    다시 시도해주세요.

"로컬 서버를 시작하지 못했습니다"
  → 이미 다른 창에서 AI 전략회의실이 실행 중일 수 있습니다.
    작업 표시줄에서 기존 창을 확인해주세요.

이 외의 오류가 발생해도 검은 창은 바로 닫히지 않고 안내 문구를
보여줍니다. 화면에 나온 문구를 그대로 캡처해 문의해주시면 됩니다.

이 프로그램은 API 키를 전혀 사용하지 않으므로, Claude 연결에 문제가
있으면 화면 상단에 "● Claude 연결 안 됨"으로 명확히 표시되고 실제
회의는 시작되지 않습니다 — 실패를 감추고 가짜 결과를 보여주지
않습니다. 화면 구성과 사용법만 미리 확인하고 싶다면 입력 화면의
"예시 보기" 버튼을 눌러주세요 (실제 AI 결과가 아닌 예시입니다).


--------------------------------------------------------------------
[보안 관련 안내]
--------------------------------------------------------------------

- 이 프로그램은 Anthropic/OpenAI API 키를 전혀 사용하지 않습니다.
  API 키를 입력하는 화면 자체가 존재하지 않으며, 관련 코드도
  포함되어 있지 않습니다.
- Claude 로그인 정보(인증 토큰)는 이 프로그램 폴더에 복사되거나
  저장되지 않습니다 — Claude Code가 공식적으로 관리하는 이 PC의
  로그인 정보를 그대로 사용할 뿐입니다.
- 회사 PC에서 사용할 경우, 입력한 주제와 첨부한 참고자료 내용은
  전략회의 분석을 위해 이 PC에 로그인된 Claude Code로 전달됩니다.
  민감한 개인정보나 기밀 자료는 첨부하지 않도록 주의해주세요.
