====================================================================
AI 전략회의실 — 설치 및 사용 안내 (Windows)
====================================================================

이 프로그램은 집 PC와 회사 PC 어디서든, 폴더를 통째로 복사해서
사용할 수 있습니다. Python이나 Node.js 설치가 필요 없습니다.


--------------------------------------------------------------------
[처음 한 번만 하면 되는 준비 작업]
--------------------------------------------------------------------

1) Claude Code 설치 (PC마다 최초 1회)

   Windows PowerShell을 열고 아래 명령을 입력합니다.
   (시작 메뉴 → "PowerShell" 검색 → 실행)

       irm https://claude.ai/install.ps1 | iex

   * 이 설치 방식은 Node.js를 별도로 요구하지 않는 Claude Code의
     공식 네이티브 설치 방법입니다.
   * 만약 이 명령이 동작하지 않는다면(사내 정책 등으로 막힌 경우),
     https://docs.claude.com/ko/docs/claude-code 공식 문서에서
     현재 사용 가능한 Windows 설치 방법을 확인해주세요.
   * 이 부분은 사내 보안 정책에 따라 회사 PC에서는 IT 담당자의
     설치 허가가 필요할 수 있습니다.

2) Claude 계정 로그인 (PC마다 최초 1회)

   설치가 끝난 새 PowerShell(또는 명령 프롬프트) 창에서:

       claude auth login

   을 입력하면 브라우저가 열립니다. 평소 쓰시는 Claude 계정으로
   로그인해주세요.

   ⚠ 중요: 로그인할 때 "Claude 구독 계정(Pro/Max/Team 등)"으로
   로그인해야 별도의 API 사용료 없이 사용할 수 있습니다.
   "Anthropic Console(API 키)" 계정으로 로그인하면 사용량만큼
   별도로 과금되니 주의해주세요. (기본값은 구독 계정 로그인입니다.)

   로그인이 잘 됐는지 확인하려면:

       claude auth status

   결과에 "loggedIn": true 라고 나오면 정상입니다.


--------------------------------------------------------------------
[매번 사용하는 방법]
--------------------------------------------------------------------

1) ai-strategy-room 폴더를 통째로 복사합니다.
   (index.html만 따로 옮기면 동작하지 않습니다. css, js, scripts
   폴더가 모두 같은 위치에 있어야 합니다.)

2) 폴더 안의 "AI전략회의실.bat" 파일을 더블클릭합니다.

3) 검은 창이 뜨고 자동으로 상태를 확인한 뒤, 문제가 없으면
   기본 웹 브라우저가 자동으로 열립니다.

4) 브라우저 화면에서:
     - 주제 입력
     - (필요하면) 참고자료 파일 선택
     - "전략회의 시작" 클릭
   → 이 PC에 로그인된 Claude Code가 실제로 7명의 전문가 역할로
     서로 반박·검증하며 회의를 진행하고, 완성된 보고서를 보여줍니다.

5) 다 사용했으면 검은 창을 닫으면 프로그램이 종료됩니다.


--------------------------------------------------------------------
[화면에 오류 안내가 나오는 경우]
--------------------------------------------------------------------

"Claude Code가 설치되어 있지 않습니다"
  → 위 [1) Claude Code 설치] 순서를 진행해주세요.

"Claude 로그인이 필요합니다"
  → 새 창에서 claude auth login 을 실행해 로그인한 뒤,
    AI전략회의실.bat 을 다시 실행해주세요.

"로컬 서버를 시작하지 못했습니다"
  → 이미 다른 창에서 AI 전략회의실이 실행 중일 수 있습니다.
    작업 표시줄에서 기존 창을 확인해주세요.

이 외의 오류가 발생해도 검은 창은 바로 닫히지 않고 안내 문구를
보여줍니다. 화면에 나온 문구를 그대로 캡처해 문의해주시면 됩니다.

만약 AI 연결에 계속 문제가 있어도, 프로그램 자체는 "데모 모드"로
동작해 화면 구성과 사용법을 그대로 확인할 수 있습니다.


--------------------------------------------------------------------
[보안 관련 안내]
--------------------------------------------------------------------

- 이 프로그램은 API 키를 코드 안에 저장하지 않습니다.
- Claude 로그인 정보(인증 토큰)는 이 프로그램 폴더에 복사되거나
  저장되지 않습니다 — Claude Code가 공식적으로 관리하는 이 PC의
  로그인 정보를 그대로 사용할 뿐입니다.
- 회사 PC에서 사용할 경우, 입력한 주제와 첨부한 참고자료 내용은
  전략회의 분석을 위해 Claude(Anthropic)로 전송됩니다. 민감한
  개인정보나 기밀 자료는 첨부하지 않도록 주의해주세요.
- Anthropic/OpenAI API 키를 직접 입력하는 방식(화면 우측 상단
  "⚙ AI 연결 설정")은 보조 옵션이며, 이 방식을 사용하면 별도로
  API 사용료가 청구될 수 있습니다. 특별한 이유가 없다면 이 설정은
  비워두고 기본 방식(이 PC의 Claude Code)을 사용하시길 권장합니다.
