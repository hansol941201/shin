# POUR 홍보영상 — 이미지 투입 가이드

이미지를 `assets/` 폴더에 넣고 다시 렌더링하면 플레이스홀더가 실제 사진으로 대체됩니다.
AI 생성 이미지는 사용하지 않습니다. 파일이 없는 슬롯은 라벨이 붙은 플레이스홀더로 남습니다.

## 사용법
1. 아래 슬롯 이름으로 파일명을 지정해 `assets/`에 저장 (예: `apt_wide_1.jpg`)
   - 슬롯명으로 시작하거나 슬롯명을 포함하는 파일명이면 자동 매칭됩니다.
   - 파일명을 바꾸기 싫으면 `assets/map.json`에 `{"apt_wide_1": "실제파일명.jpg"}` 형태로 지정
2. `node render.js` 실행 (환경변수 `OUT=파일명.mp4`, `FPS=30`)

## 권장 사양
- 배경용(`apt_wide_1`, `factory_yongin`, `drone_1`): 가로 2400px 이상, 16:9 근사
- 카드용: 가로 1200px 이상
- 문서류(`mou_doc`, `netform_doc`): 원본 스캔 그대로, `object-fit: contain`으로 잘림 없이 표시
- 자재(`material_*`): 배경 투명 PNG면 그대로, 아니면 흰색 카드 위에 배치됨

## 자막 / 내레이션
- 현재 버전은 무음 + 하단 자막입니다.
- 내레이션 음원을 넣을 때: `film.html`의 `#sub { opacity:0 }` 처리 또는 `film.js` 하단 자막 painter 제거 후 재렌더 → ffmpeg으로 오디오 먹싱
- 대본 타이밍은 `film.js`의 `SCRIPT` 배열과 `RATE`(9.2자/초)로 자동 계산됩니다. 실제 VO 길이에 맞추려면 `RATE`를 조정하면 전체 모션이 함께 따라갑니다.

## 연번 슬롯의 자동 레이아웃

`material_1~4`, `seminar_1~3` 처럼 번호가 붙은 슬롯은 **실제로 들어온 장수에 맞춰 배치가 재구성**됩니다.
1장만 있으면 그 1장을 크게, 3장이면 3분할로 놓습니다. 빈 자리를 플레이스홀더로 채우지 않습니다.
해당 계열이 **하나도 없을 때만** 어떤 원본이 필요한지 보이도록 전량 플레이스홀더로 남습니다.

## 문서 이미지 처리

`consulting_1`, `cad_1`, `mou_doc`, `netform_doc`은 세로형 문서라 잘림 없이 `contain`으로,
밝은 바탕(`#F4F7FB`) 위에 올립니다. 문서 내용은 어떤 방식으로도 수정하지 않습니다.

## 주의 — 이 폴더의 이미지는 커밋되지 않습니다

`assets/`는 `.gitignore`에 걸려 있습니다. 컨설팅 내역서·공문·MOU에는 발주처명, 계약금액,
연락처 등이 담겨 있어 저장소에 올리지 않습니다. 렌더링에만 로컬로 사용하세요.

## 누끼(흰 배경 제거)

제품컷의 흰 배경은 `cutout.js` 로 제거한다.

```bash
node cutout.js assets/material_1.png assets/material_1.png
```

제품 자체가 흰색인 경우(파우더 봉투, 페인트 통)가 많아 단순 임계값으로는
제품이 지워진다. 그래서 이렇게 처리한다.

1. 밝고 채도 낮은 픽셀을 배경 후보로 잡는다
2. 후보를 2px 침식해 배경과 제품을 잇는 얇은 통로를 끊는다
   (이 단계가 없으면 하이라이트를 타고 제품 안으로 새어 들어간다)
3. 화면 테두리에서 flood fill — 바깥과 이어진 영역만 배경이다
4. 후보 범위 안에서만 4px 팽창해 제품 경계까지 회복한다
5. 경계는 알파 램프 + 흰색 언프리멀티플라이로 흰 테두리를 없앤다
6. 내용 경계로 잘라 여백을 제거한다

투명 배경이 감지되면 `film2.js` 가 흰 받침대 없이 배경 위에 제품만 놓고,
색보정도 걸지 않는다. 불투명하면 기존 흰 받침대로 돌아간다.

원본은 `_original/` 에 보관한다(커밋되지 않음).
