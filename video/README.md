# 문서 스택 영상 (POUR 견적서 5종)

`output/pour_document_stack_1080p.mp4`
견적 문서 5장이 화면 위에서 한 장씩 내려와 차곡차곡 쌓이는 7초 분량의 홍보 영상.

## 사양
| 항목 | 값 |
|---|---|
| 해상도 / 화면비 | 1920 × 1080 (16:9) |
| 길이 / 프레임 | 7.00초 / 30fps (210프레임) |
| 코덱 | H.264 (High@4.0), yuv420p, `+faststart` |
| 오디오 | 없음 |
| 용량 | 약 4.5 MB |

## 개인정보 처리
영상에 쓰이는 이미지는 `mask_pii.py`로 식별 정보를 먼저 모자이크 처리한다.
해당 영역을 블록 단위로 다운샘플 → 업샘플 하므로 원래 픽셀이 실제로 파괴되어
복원이 불가능하고, 그 위에 약한 블러와 가장자리 페더링만 얹어 문서에 자연스럽게
녹아들게 했다. 영역의 크기·위치·표 칸 구조는 그대로라 문서 구도는 변하지 않는다.

| 문서 | 가린 항목 |
|---|---|
| 02_안내사항 | 견적일자(날짜), 발주처(고객사명), 업체 상호, 법인 인감, 업체 로고 워드마크, 주소, 전화·팩스번호, 동·호수 |
| 07_물량산출내역서 | 현장명(아파트명) |
| 03_원가계산서 / 04_집계표 / 06_산출내역서 | 없음 (공종·자재·금액만 기재되어 가릴 항목 없음) |

모자이크 전 원본은 `video/_src_private/`에 두고 `.gitignore`로 커밋에서 제외한다.

## 배경
기존 색감(짙은 네이비 → 차콜, 중앙이 가장 밝은 배치)은 유지한 채 다음을 아주 낮은
대비로 얹어 공간감을 만들었다. 모든 장식은 중앙에서 최대 94%까지 눌려 사라지므로
시선은 계속 문서에 머문다.

- 세로 그라데이션 + 중앙 주광 + 왼쪽 위 방향광
- 문서가 놓이는 면을 암시하는 옅은 수평 띠와 아래쪽 감광
- 추상 장식: 화면 밖 중심의 동심원 호 2세트, 사선 광선 2줄, 큰 블러 덩어리 4개, 헤어라인 6줄
- 더미가 쌓일수록 짙어지는 넓은 앰비언트 그림자(바닥 그림자)
- 화면 고정형 미세 필름 그레인(반해상도 노이즈를 키워 뭉치게 함)
- 배경 비네팅 + 합성 후 화면 전체에 얹는 아주 약한 렌즈 비네팅

## 연출
- 0.00~0.25초: 문서 없이 배경만 (위 "배경" 항목 참고)
- 0.25초부터 1.05초 간격으로 한 장씩, 화면 위에서 1.0초에 걸쳐 내려옴
- 내려오는 동안 좌우 이동(±60~86px)과 1.4~2.2° 회전이 서서히 풀림
- 안착 시 부드러운 감속 후 약 20px(종이 높이의 2.5%)짜리 미세 바운스 2회
- 장마다 위치(±28px)·각도(-2.4°~+2.5°)·높이 배율이 달라 실제 서류 더미처럼 보임
- 종이가 떠 있을수록 그림자는 크고 옅게, 안착하면 짧고 진하게(접지 그림자 추가)
- 5.45초에 마지막 장 안착 → 1.55초간 완성된 더미 유지
- 카메라는 전체 구간에 걸쳐 1.000 → 1.049 배로 아주 천천히 확대(후반부에 더 밀어 넣음)
- 제목/문구/자막/로고 없음, 원본 이미지 비율(√2, 2000×1413) 그대로 유지

## 다시 만들기
```bash
pip install pillow numpy imageio-ffmpeg
python3 video/mask_pii.py          # _src_private/ -> images/ (모자이크)
python3 video/render_stack_video.py
```
`video/images/`의 모자이크된 5개 PNG를 순서대로 읽어 `video/output/`에 MP4를 씁니다.
가릴 영역은 `mask_pii.py`의 `REGIONS`(원본 2000×1413 기준 좌표)에서 조정합니다.
연출 값은 `render_stack_video.py` 상단의 `LAYOUT`, `T_FIRST`, `STAGGER`, `DROP`,
`ZOOM_END`, `PAPER_W`에서, 배경 강도는 `make_background()`의 장식 진폭과 `guard`에서 조정합니다.
