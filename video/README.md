# 문서 스택 영상 (POUR 견적서 5종)

`output/pour_document_stack_1080p.mp4`
견적 문서 5장이 화면 위에서 한 장씩 내려와 차곡차곡 쌓이는 7초 분량의 홍보 영상.

## 사양
| 항목 | 값 |
|---|---|
| 해상도 / 화면비 | 1920 × 1080 (16:9) |
| 길이 / 프레임 | 7.00초 / 30fps (210프레임) |
| 코덱 | H.264 (High@4.0), yuv420p, `+faststart` |
| 오디오 | 없음 |
| 용량 | 약 3.1 MB |

## 연출
- 0.00~0.25초: 빈 배경(짙은 네이비-차콜 그라데이션 + 은은한 중앙 광량 + 비네팅)
- 0.25초부터 1.05초 간격으로 한 장씩, 화면 위에서 1.0초에 걸쳐 내려옴
- 내려오는 동안 좌우 이동(±60~86px)과 1.4~2.2° 회전이 서서히 풀림
- 안착 시 부드러운 감속 후 약 20px(종이 높이의 2.5%)짜리 미세 바운스 2회
- 장마다 위치(±28px)·각도(-2.4°~+2.5°)·높이 배율이 달라 실제 서류 더미처럼 보임
- 종이가 떠 있을수록 그림자는 크고 옅게, 안착하면 짧고 진하게(접지 그림자 추가)
- 5.45초에 마지막 장 안착 → 1.55초간 완성된 더미 유지
- 카메라는 전체 구간에 걸쳐 1.000 → 1.049 배로 아주 천천히 확대(후반부에 더 밀어 넣음)
- 제목/문구/자막/로고 없음, 원본 이미지 비율(√2, 2000×1413) 그대로 유지

## 다시 만들기
```bash
pip install pillow numpy imageio-ffmpeg
python3 video/render_stack_video.py
```
`video/images/`의 5개 PNG를 순서대로 읽어 `video/output/`에 MP4를 씁니다.
연출 값은 스크립트 상단의 `LAYOUT`, `T_FIRST`, `STAGGER`, `DROP`, `ZOOM_END`, `PAPER_W`에서 조정합니다.
